# Absolute-quality preference comparison

The **filtered-DPO arm is complete**; the optional CE-anchored arm is not
launched. The preceding middle-attention experiment finished through
update 32 and stopped on two consecutive speech-harm warnings. No previous
checkpoint met both groups' joint thresholds. All five filtered-run checkpoints
are now audited; none passes. The run stopped at update 32 for speech regression.

## Motivation and controlled comparison

The current pool accepts relative improvements even when the chosen output
still has poor pronunciation or reference similarity. Of 357 fitting pairs,
137 have a chosen output with CER strictly below 3% and internal original-
reference cosine strictly above 0.984. These cover 41 cases and 29 speakers,
versus the original 94 cases and 48 speakers. Thus filtering has a substantial
diversity cost. It must not be described as an established improvement.

The comparison isolates the two ideas:

1. Filter fitting pairs by absolute chosen quality; retain the current DPO.
2. Use the same filtered fitting pairs and add 0.1 times mean chosen-token
   negative log likelihood to the DPO objective.

Both start from the same original speaker-update-8 policy with zero
middle-attention LoRA and fresh optimizer moments. Keep the same LoRA coverage,
generation settings, scorer and speech criteria. Preserve the full 120-pair,
16-speaker preference-validation panel; do not filter validation to make its
reported metrics easier. Also retain all-pool fitting diagnostics and label
effective-subset diagnostics separately. The 26-recording speech screen and
114-recording confirmation remain unchanged. No evaluation target is a fitting
example. The implemented trainer is `training/quality_preference_training.py`.
Its registered checkpoints are 0, 4, 8, 16 and 32, with the same seed, rank-4
Q/V layers 10–17, FP32 optimizer, 16 pairs per update, learning-rate schedule
and weight bound as the preceding unfiltered run. The effective subset changes
speaker-balanced sample visits; exposure is recorded for every fitting pair.

The external driver runs training, all 26 speech recordings, ASR scoring and an
independent audit sequentially at each checkpoint. It stops after a joint pass
for broader confirmation, after two consecutive speech-harm warnings, or after
two validation-loss rises while effective-fitting loss decreases. It does not
automatically switch to the anchored arm or promote a model.

## Prepared objective and checks

`training/quality_preference_objective.py` implements a non-mutating strict
quality filter, with generated-training origin, split, matching-condition,
termination and metric guards. It selects 137 fitting and 39 validation pairs
when applied for the **read-only coverage audit**; the latter is not a proposal
to remove validation cases.

The optional objective is:

`DPO(raw joint sequence log probabilities) + 0.1 * (-chosen_logp / chosen_tokens)`

The CE denominator includes all 16 codec targets and EOS. DPO remains a raw
sequence-likelihood objective. Replaying one chosen/rejected trajectory graph
at a time preserves the full objective gradient while limiting memory. Zero
SFT weight gives ordinary DPO. No historical registered module was edited.

Three CPU tests pass. A tiny actual Qwen model verifies replay against a direct
full-graph calculation for unequal trajectory lengths, both zero and nonzero
anchor weights, and frozen acoustic/speaker parameters. Other tests exercise
strict thresholds, no input mutation, split leakage, changed reference, invalid
metrics and non-generated/truncated data. These are numerical and provenance
checks, not speech-quality evidence.

Two additional CUDA tests pass for zero/nonzero anchor weights. They compare
resumed versus uninterrupted fitting, verify that an excluded training pair
never reaches backward passes, retain full validation diagnostics, and check
FP32 moments plus frozen original acoustic/speaker parameters. Eight confirmation
tests pass, including loading a `--kind quality` candidate and rejecting a
changed frozen speaker adapter. A real CPU FP32 no-update control reproduces
the original update-8 waveform exactly. Historical registered sources remain
unchanged.

## Observability and independent checks

The new run reports both the full 357-pair training pool and the actual 137-pair
fitting subset, alongside all 120 validation pairs. Fixed probes retain all 480
original chosen/rejected trajectories. Save their raw log probabilities at
each checkpoint, with chosen/rejected mean token NLL and policy/reference
log-ratio summaries. These fixed samples distinguish distribution drift from
changing minibatches. The loss gap retains the original full-pool definition;
the effective-subset metrics are explicitly separate.

The independent auditor verifies subset membership and split coverage, every
visited training pair, probe artifact hashes and recomputed probe aggregates,
native original acoustic/speaker identities, LoRA coverage and FP32 moments.
It also verifies every speech/reference hash, recomputes ASR edit counts and
re-extracts original-reference cosines. It does not independently rerun ASR or
all fixed-probe model likelihoods. At update zero, all 480 likelihoods must
exactly match the preceding unchanged policy cache and all 26 waveforms must
match the original update-8 screen.

Artifacts remain outside Git under `quality-filtered-pilot/`, with
`quality-filtered-fit-registration.json` and `quality-filtered-pipeline-status.json`
in the external experiment root. The driver and auditor are pinned along with
the source/runtime, test evidence, native control and existing data-separation
receipt. This is a new run; accepted model selection remains unchanged.

[calibrated comparison](0.6b-calibrated-quality-preferences.md) uses rounded
weight 5. This is an engineering calibration on fitting data, not a claim of
optimal weighting or demonstrated speech improvement.

`2e519d3dc5201de8fb0a608abc625ca1e5c81cde8324890772394c9bb6904d75`.

loss also falls to 0.687899 with 65.73% accuracy. Full training-pool loss is

The selected-trajectory likelihoods increase while generated voice deteriorates;
there is no evidence of chosen-likelihood collapse here. Neither lower loss

**Outcome:** the strict quality filter has not solved the joint target. No
checkpoint qualifies for the 114-recording confirmation and no model is
promoted. The comparison dashboard now includes every audited checkpoint.

## Voice-error localization

At filtered update 4, custom-007 seed 2026 has zero ASR character errors but
cosine 0.964556, while seed 2027 has zero errors and cosine 0.986501. Durations
are only 4.48 and 4.64 seconds. This rejects a simple duration-only explanation
for the voice gap; it does not establish which decoder component causes it.
Do not discard the bad seed. Earlier manual phrase chunking also severely
reduced judged naturalness on a distinct 20-sentence comparison, documented in
[listening findings](listening-findings-2026-11-04.md). That result does not rule
out every chunking algorithm, but does not justify adopting it here.

The rationale and limitations are in the
[literature review](0.6b-joint-goal-literature.md#follow-up-absolute-preference-quality-and-regularization).
MPO's CE regularization and Magpie's absolute selection are inspirations, not
claims of reproducing those systems or their results.
