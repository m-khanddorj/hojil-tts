# Supervised loss scaled from training gradients

The calibrated run is **registered and launched**. The filtered-DPO run finished
without a joint pass. Fitting preference accuracy
reached 97.79% and validation loss improved while generated speech worsened.
This follow-up tests whether increasing the likelihood of good chosen outputs
alongside relative preference training helps. No quality improvement is yet
established, and the accepted model is unchanged.

## Training-only calibration

The original 0.1 CE weight comes from a literature-inspired proposal, but loss
units differ between sequence-summed DPO and token-averaged CE. A read-only
diagnostic measured actual gradients on the initial zero-LoRA policy, using
one chosen/rejected pair from each of the 29 fitting speakers. No optimizer
steps, development/custom targets or speech selection were involved. Frozen
acoustic weights, the original speaker adapter and all LoRA parameters were
verified unchanged.

| Probe | DPO norm | Unit-weight CE norm | CE at weight 0.1 / DPO norm |
| --- | ---: | ---: | ---: |
| First 16 fitting pairs | 2.565690 | 0.094592 | 0.369% |
| All 29 fitting speakers | 1.764817 | 0.089572 | 0.508% |

On the 29-speaker probe, CE/DPO gradient cosine is 0.270828. Weight 0.1 changes
the combined direction very little (cosine 0.999988 to DPO). A 25% relative
gradient-norm target gives weight 4.925715; use **5**, rounded before fitting.
This is approximately 25.38% on all 29 pairs and 18.43% on the first 16.
These initial gradients do not guarantee the same balance later in training
or establish that a stronger supervised term improves speech.

## Controlled change

Objective: `DPO + 5 * chosen mean token NLL`. DPO uses raw summed likelihoods
for all 16 codebooks and EOS; mean NLL uses the corresponding token count.
Keep the same 137 fitting pairs, full 120-pair validation set, original update-8
speaker adapter, zero-initialized rank-4 Q/V LoRA on layers 10–17, seed, optimizer,
learning-rate schedule, checkpoints 0/4/8/16/32, weight bound and speech panel.
The only intended fitting change from the filtered arm is supervised weight 5.
Fixed-probe diagnostics retain all 480 trajectories and distinguish the actual
fitting subset from the full training pool.

Historical registered sources remain unchanged. New entry points are
`training/calibrated_quality_training.py` and
`training/confirm_calibrated_candidate.py --kind calibrated`. The latter retains
all 114 confirmation recordings, both seeds, original scorers and strict joint
thresholds. Every checkpoint still requires an independent model/data/audio
audit; no automatic promotion occurs.

Three focused tests pass: exact replayed versus full-graph gradients at weight
5; CUDA resumed versus uninterrupted fitting with filtered-pair exclusion,
full validation and frozen-state checks; and calibrated-candidate loading with
rejection of a tampered frozen speaker adapter. The real native no-update
control exactly reproduces the original speaker-update-8 waveform and pins the
final trainer source. The confirmation panel-validation, record-coverage and
preparation functions are structurally identical to the existing tested runner.

Artifacts are outside Git under the experiment root: the gradient diagnostic
is `quality-anchor-gradient-diagnostic.json`; the active run is
`quality-calibrated-pilot/`. Its registration is
`quality-calibrated-fit-registration.json` and status is
`quality-calibrated-pipeline-status.json`. The registration pins the gradient
calibration, final source/runtime, tests, native control, external driver/auditor
and separate confirmation runner. Preparation and the complete update-0 audit
passed. All 26 baseline waveform hashes exactly match original speaker update
8, and all 480 initial raw likelihoods exactly match the filtered control.
Original acoustic/speaker identity, zero LoRA movement, full validation and
probe aggregates are verified; cosine re-extraction discrepancy is zero.
Update 4 has completed all 26 recordings and passed the independent audit.

Custom-reference cosine is 0.00359476 below the initial policy, and the worst
recording's decrease is 0.00849158. Both CERs and custom voice fail the goal.
Effective fitting-subset DPO loss still falls to 0.656860 and full validation

Chosen mean NLL also falls. Thus neither improving validation loss nor the
supervised anchor prevented speech regression; the preference-overfit rule
did not trigger. This evidence does not establish classical validation-loss
overfitting, and does not justify additional epochs on this objective.

All 26 recordings, fixed-probe telemetry, dataset scope and frozen state pass
the independent audit; cosine re-extraction discrepancy is zero. Maximum
audited matrix displacement is 0.00055363. No checkpoint passes the joint screen,
no 114-recording confirmation is eligible, and the accepted model is unchanged.
The next separately registered experiment is the
[residual-temperature calibration](0.6b-residual-sampling-calibration.md).

A read-only effective-weight diagnostic confirms that the intended objective
change affects training. The real first-batch gradient norm is 2.776531696,
versus 2.776531398 predicted from the independent calibration (difference
2.98e-7). At update 4, the effective BA LoRA updates differ from the filtered
run by 24.97% of that run's update norm; their cosine is 0.969210. This is
parameter-update cosine, not speaker cosine. The comparison uses the low-rank
factor contraction, checked against a dense small-matrix calculation, and
verified checkpoint hashes with identical frozen acoustic/speaker state.
`quality-anchor-update-diagnostic.json` records the details. These checks
establish a meaningful numerical comparison, not better generated speech.

The shared `quality-filtered-comparison.html` now charts all three experiments
and reports matched filtered-versus-calibrated differences as their audits
finish. Its underlying JSON labels each comparison by before/after run, and
retains the earlier unfiltered-versus-filtered evidence.
Its twelve charts include both groups' CER, WER and cosine, common full-pool
training/validation DPO losses and their gap, the actual filtered fitting-subset
loss, and chosen-token NLL on the common training/validation pools. The latter
is displayed only for the two trainers that recorded it. This distinguishes
the fitted subset from the diagnostic pool and avoids comparing weighted total
objectives with different supervised coefficients. All charts use independently
audited speech checkpoints; SVG structure and local artifact links are checked.
