# Reference-audio-only weight routing

The preceding reference/control routing passes both voice thresholds but
worsens CER to 4.93%/5.61%. Its target-text rows still attend earlier reference
text/control states that were computed with halfway matrices. This ablation
tests preserving those text representations while changing only reference
audio processing.

Start from the same audited centered update 16. Keep all text projections,
control/speaker rows, reference text, target text and text EOS fully adapted.
Only the subsequent codec BOS and reference codec rows use halfway matrices
in the 196 main-decoder linears. Generated frames and output/residual heads
remain fully adapted. Speaker conditioning, prompts, seeds and the 26-recording
screen remain unchanged. No optimizer or alternate-matrix parameter search is
part of this comparison.

Each protected generation includes a separate full-weight prefill on an
independent temporary cache. Every hidden state before the reference-audio
boundary must match that full-weight result **exactly**. The temporary cache
is discarded, and native generation uses its own routed cache. This checks
the intended text-preservation property on every case; it does not guarantee
generated pronunciation because subsequent frames attend changed audio context.

Three CPU tiny-Qwen tests pass: native no-op codec parity, exact earlier hidden
states with altered audio states and full-weight cached decoding, and cleanup
after a forced decoder failure. The actual model's no-op control reproduces
centered update-16 custom-001/seed-2026 audio exactly. The experiment is
registered and running in `reference-codec-half-routing/` outside Git.

The pipeline generates all 26 cases, scores pinned ASR CER/WER and original-
reference cosine, and independently audits the 196 matrices, model states,
audio/trajectory hashes, EOS, routing boundaries and recorded exact text-state
checks. A joint screening pass still requires the same registered 114-recording
confirmation.

The completed comparison fails the joint screen:

| Group | CER | WER | Original-reference cosine |
| --- | ---: | ---: | ---: |
| Development | 3.6313% | 10.3448% | 0.984573 |
| Custom reference | 3.0374% | 6.2500% | 0.981488 |

All 26 recordings terminate normally. Independent verification passed for
all 196 matrices, trajectories/EOS, artifact identities, ASR edit counts,
recorded exact earlier-state checks and re-extracted cosines (zero discrepancy).
Compared with broader reference/control routing, pronunciation recovers in both
groups but custom voice similarity falls. Compared with centered update 16,
custom CER and cosine improve, while development CER worsens. No promotion or
114-recording confirmation is warranted.
