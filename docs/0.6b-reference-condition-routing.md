# Speaker plus reference-audio weight routing

The verified codec-only comparison recovers pronunciation relative to broader
reference/control routing but misses the custom voice threshold. This ablation
adds one routed position: the native speaker-conditioning position, index 6
under the registered full-ICL Auto-language layout.

The same centered update-16 policy and the same 196 halfway main-decoder
matrices remain fixed. Only position 6, reference codec BOS and reference codec
rows use the alternatives. All text projections, other direct text/control
mappings, cached generated frames, acoustic output/residual heads and the
speaker adapter remain unchanged. No optimizer, strength sweep or per-case
selection is used. This is an experimental weight-routing hypothesis inspired
by Weight-Space Programming, not a reproduction of its language-model results.

Text positions can attend changed speaker states, so their hidden states are
**not** claimed unchanged. A separate full-weight prefill checks that positions
0–5 are exact on every generation. Tiny native-Qwen tests check no-op codec
parity, every main linear's actual routed mask/output, exact text projections,
full cached decoding, unchanged parameters, leading states and exception
cleanup. All three tests pass.

The pipeline first requires actual-model no-op waveform parity with centered
update 16, then generates all 26 registered recordings and evaluates CER/WER
and original-reference cosine. An independent audit checks all matrices,
artifacts, sampled codecs/EOS, spans, score aggregates and re-extracted cosines.
A verified joint pass must still pass the existing 114-recording confirmation.
No quality result or model promotion is claimed at launch. Artifacts live
outside Git in `reference-condition-half-routing/`.

The completed 26-recording comparison was independently verified, with no
truncations and zero cosine recomputation discrepancy:

| Group | CER | WER | Original-reference cosine |
| --- | ---: | ---: | ---: |
| Development | 3.0726% | 10.3448% | 0.984678 |
| Custom reference | 7.7103% | 20.3125% | 0.982240 |

The added speaker-position change slightly improves development CER and both
group cosines relative to codec-only routing, but sharply worsens custom CER.
It fails the joint target and is rejected. No model promotion or expanded
confirmation follows. Further arbitrary position combinations are not justified
by this result; the next approach fits a small middle-attention LoRA to joint
generated-speech preferences with the original speaker adapter frozen.
