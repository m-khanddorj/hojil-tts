# Reference-only speaker-input adaptation

The target-only weight transfer improved development pronunciation but badly
regressed custom pronunciation. The bounded generated-preference pilot also
failed to improve speech. This follow-up changes the conditioning variable:
freeze the complete epoch-2 LoRA model and adjust only its input speaker vector.
The accepted halfway voice remains selected.

ASRRL-TTS motivates testing speaker-embedding adjustments with simultaneous
intelligibility and voice measurements. Its method uses reinforcement learning
on VITS/Grad-TTS and English corpora. This experiment instead uses reference
codec reconstruction; it is **not a reproduction**, and lower reference loss
does not establish better synthesized voice.
[Primary source](https://arxiv.org/html/2407.05421v1).

## Registered calibration

- Four hash-selected speakers from the existing original-training rollout
  cohort, one separate target transcript each, two fixed seeds: 2026/2027.
- Adapt on the supplied reference audio and its transcript only. Reference
  codes are supervision with speaker-vector conditioning, without feeding the
  same reference audio as an ICL prefix. Evaluation uses normal full ICL and a
  different target transcript. This train/inference conditioning difference
  is explicit; successful generalization must be measured.
- Full epoch-2 model, original speaker encoder and codec, all frozen. This is
  per-reference input adaptation, not further LoRA or full model fine-tuning.
- FP32 normalized gradient descent, at most 32 steps. L2 displacement is bounded
  to 5% of the original vector norm; each step is one-sixteenth of that radius.
- Loss: mean main-codebook CE plus 0.3 times mean residual-codebook CE, matching
  the existing supervised loss weighting. Neither generated target scores nor
  evaluation target audio enter its gradients.
- Checkpoints 0, 8 and 32 each get eight CPU FP32 speech recordings, pinned
  ASR CER/WER, original-reference cosine and natural-termination checks.
- Fit observability: main/residual CE, gradient norm, displacement and peak
  GPU allocation. Model hashes before/after verify weights stay frozen.
- Expand to the fixed two-group screen only if mean voice cosine increases,
  pooled CER/WER do not increase, and no clip cosine declines by over 0.005.
  Even passing calibration does not satisfy the overall goal.

All four speakers belong to the original supervised training data: this is
calibration evidence, not unseen-speaker or held-out-test evidence. The custom
reference and development examples are excluded from this first experiment.
Any later reference adaptation there must be labeled as test-time adaptation,
reset per reference, use no target audio, and retain its unadapted control.

The implementation lives in `training/speaker_reference_adaptation.py`.
Historical sequence/routing modules remain unchanged. Focused tests compare
the constructed prefix and speaker-position perturbation with native Qwen
generation, check a finite-difference CE gradient, confirm frozen parameters
receive no gradients, and check the trust-region bound. Runtime inputs,
weights, source and results are hashed; audio/embeddings live outside Git.

## Completed calibration

All 24 scheduled recordings completed with natural EOS. No model weights were
changed, all speaker updates obeyed the 5% bound, and 77 training tests passed.
An independent audit checked all reference/audio/embedding hashes, model
identity, input bounds, ASR edit counts and pooled aggregates. Cosines were
re-extracted from audio; maximum discrepancy was 2.39e-7. The external run
folder contains `verification.json`, `decision.json` and paired listening in
`report.html`.

| Input steps | Calibration CER | Calibration WER | Mean original-reference cosine |
| --- | ---: | ---: | ---: |
| 0 | 3.02% | 3.45% | 0.983795 |
| 8 | 4.12% | 8.62% | 0.983140 |
| 32 | 4.12% | 13.79% | 0.983787 |

Neither adapted checkpoint passes the registered expansion gate. The 32-step
voice difference is tiny, not evidence of meaningful perceptual degradation;
the important failure is no demonstrated voice gain and worse pronunciation.
Reference reconstruction loss fell for all four speakers (3.094→2.902,
3.457→3.088, 3.691→3.440 and 3.368→3.182), yet different-text synthesis did not
improve. This is evidence against continuing this particular reference-loss
recipe, not against all speaker-conditioning adaptation or ASRRL's generated
speech reward. Eight recordings per checkpoint is a small calibration sample.

Stop this fit without expanding to development/custom data. Keep the accepted
halfway voice unchanged. Any next conditioning experiment should optimize or
select using generated pronunciation **and** original-reference voice, rather
than treating lower reference reconstruction CE as a proxy for both.
