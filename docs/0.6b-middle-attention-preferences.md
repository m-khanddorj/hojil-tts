# Joint preferences in middle talker attention

The speaker-position routing ablation is rejected: development/custom CER is
3.07%/7.71%, with cosine 0.984678/0.982240. Three routing comparisons did not
establish a reliable separation of pronunciation and identity. The earlier
speaker-only preference fits also showed fitting gains without sufficient
two-group speech gains. This experiment expands the trainable representation
while keeping the earlier speaker adapter fixed.

## Registered fit

Start from the independently audited original speaker update 8 on the full
epoch-2 acoustic model. Add rank-4, unit-scaled FP32 LoRA to Q and V projections
in main talker layers 10–17 (zero-indexed): **16 projections, 163,840 trainable
parameters**. Original acoustic weights, the existing speaker adapter, encoder,
codec and residual-codebook predictor remain frozen. This modifies attention
throughout the native prefix and generated sequence; it is not reference-row
routing and does not claim unchanged text or speaker hidden states.

The middle-layer choice is a bounded hypothesis informed by the Qwen activation
steering study's layer sensitivity, not proof that these layers uniquely encode
pronunciation. Generated joint preference supervision follows the earlier
Koel-TTS/preference-alignment rationale; this is not a reproduction of either
paper. See the [literature review](0.6b-joint-goal-literature.md).

Reuse the audited 508 trajectories generated by the exact update-8 policy:
357 fitting pairs across 48 speakers and 120 validation pairs across 16 other
speakers. Both candidates in each pair are generated under identical conditions;
the chosen candidate is no worse on CER or original-reference cosine. All
audio, trajectory and reference hashes and the recomputed pair list must still
match the existing independent audit. Cosines are not needlessly re-extracted
for this unchanged pool; that audit reuse is explicit in the receipt. These
speakers are from original training data; validation speakers are excluded
from this preference fit. The development/custom panel remains outside fitting.

Use actual summed likelihoods for all 16 codebooks plus EOS, a frozen update-8
DPO reference, beta 0.1, fresh FP32 AdamW moments, no weight decay, gradient clip
1, and 16 speaker-balanced pairs per update. Learning rate warms for two updates
to 2e-5 and decays to 2e-6 by update 32. Seed is 12117. Cap each effective BA
update's Frobenius norm at 1% of its original projection norm. This is a parameter
trust region, not a guarantee about speech or perceptual voice.

## Verification and observability

Three CPU tiny-Qwen tests pass: native zero-LoRA codec/likelihood parity and
canonical frozen-state identity; exact replayed DPO gradients restricted to the
new LoRA; and projection, serialization and frozen-parameter protection. A CUDA
test verifies uninterrupted versus resumed training, nonzero learning, FP32
optimizer moments and unchanged speaker/acoustic state.

The real zero-LoRA control reproduces the original update-8 custom-001,
seed-2026 waveform exactly (SHA-256 starts `5e4c40d7`). Preparation pins the
control receipt, source files, runtime, tests, reused pool audit and external
driver/auditor. Registered historical sources are unchanged.

Evaluate updates **0, 4, 8, 16 and 32** on all 26 recordings with both seeds.
Update 0 must reproduce all 26 original update-8 waveforms exactly. Report
CER/WER, speaker-macro cosine, per-seed results, truncation, paired worst-clip
voice change, fitting/validation loss and accuracy, their loss gap, per-token
log-ratio drift, gradient norm, learning rate, GPU memory and per-matrix update
norms. Speaker-input movement is retained as a constant conditioning check.

The external driver independently audits each checkpoint before proceeding:
LoRA coverage, original acoustic and speaker identities, FP32 optimizer state,
waveform/reference hashes, ASR edits/aggregates and re-extracted original-
reference cosines. It stops after two consecutive speech-harm warnings or two
consecutive validation-loss rises while fitting loss falls. A joint screening
pass stops for the unchanged 114-recording confirmation (`--kind attention`).
Seven confirmation tests pass, including a frozen-speaker tampering check.

Artifacts are outside Git in `middle-attention-pilot/`. Initialization completed
with exactly log(2) loss, 50% preference accuracy and zero policy/reference
log-ratio on both splits. All **480** trajectory likelihoods used by the paired
objective exactly match the existing update-8 CUDA FP32 reference cache. The
zero-update speech panel reproduced all 26 original waveforms exactly and
passed the independent model/audio audit with zero cosine discrepancy.

No model promotion or joint-goal pass is claimed. Prospective follow-up work is

A separate read-only target-quality audit finds that only 137/357 fitting pairs
have a chosen trajectory with CER <3% and cosine >0.984 (29/48 speakers).

Filtering could improve absolute supervision quality but reduce diversity;
neither filter has been applied to this immutable experiment. Visited-batch
chosen likelihoods mostly increase, which alone does not establish speech
quality. Artifacts: `middle-attention-paired-diagnostics.json` and
`preference-target-quality.json` under the external experiment root.
