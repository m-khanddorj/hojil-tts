# Research-driven 0.6B LoRA experiments

[Experiment summary](experiments/0.6b/README.md) · [Comprehensive report](experiments/0.6b/report.md) · [Recorded training results](experiments/0.6b/evidence/training.md#2-literature-guided-short-continuations)

Review date: 2026-11-09. The objective is better Mongolian pronunciation,
naturalness and voice preservation within the local 8 GB GPU budget. Lower
teacher-forced loss alone does not establish better generated speech. The
current incumbent before this round is `fp32-continuation-v4`, update 88:
development CER 5.65%, WER 13.24%, 44 unseen-speaker clips, generation seed 2026.
See [the audit](0.6b-training-analysis.md) for provenance and limitations.

## Literature and decisions

| Research | Finding relevant to this project | Decision |
| --- | --- | --- |
| [LoRA+ (ICML 2024)](https://arxiv.org/html/2402.12354v2) | Separate A/B learning rates can improve optimization. The useful ratio depends on model and task; reported language-model gains do not establish a TTS gain. | Test B/A = 4 against ratio 1 with identical parent weights, Adam moments, data order, rank and schedule. Hold B's maximum LR fixed; reduce A's LR. |
| [rsLoRA (2023)](https://arxiv.org/abs/2312.03732) | Scaling by the square root of rank addresses high-rank optimization problems. | Consider for a fresh rank sweep. Changing scaling on an existing adapter changes its function unless weights are transformed; do not silently enable it on this checkpoint. |
| [DoRA (ICML 2024)](https://arxiv.org/abs/2402.09353) | Separates weight magnitude and direction; reports improvements on language and vision-language tasks. | A separate capacity experiment, after measuring simpler optimizer changes. Additional trainable magnitudes and training memory need measurement on this GPU. |
| [PiSSA (NeurIPS 2024)](https://arxiv.org/abs/2404.02948) | Initializes adapters from principal weight components and freezes the residual. | Suitable for a fresh initialization comparison. Reinitializing the learned Mongolian adapter would discard its training. |
| [EVA](https://arxiv.org/abs/2410.07170) | Uses activation SVD for initialization and rank redistribution. | Promising fresh-run alternative; collect activation statistics from training data only and explicitly mask padding/prompt positions. |
| [LoRA-FA](https://arxiv.org/abs/2308.03303) | Freezing A reduces activation storage for adaptation. | Keep as a memory tradeoff, not an assumed quality improvement; the current rank-16 run already fits. |
| [Qwen3-TTS technical report (2026)](https://arxiv.org/html/2601.15621v1) | Describes quality-filtered continuation, long-context training, human preference alignment, and hierarchical first/residual codebook prediction. | Preserve both decoders and verify the data/loss contract. Prioritize a training-data quality audit before indiscriminate extra epochs. DPO requires trustworthy preference pairs, which this experiment does not have. |
| [Cawley and Talbot (JMLR 2010)](https://www.jmlr.org/beta/papers/v11/cawley10a.html) | Repeated selection on finite validation data can overfit the selection criterion. | Report all candidates and fixed seeds; keep test speakers untouched until the training/decoding recipe is frozen. |
| [Low-resource VoxCPM2 adaptation (September 2026 revision)](https://arxiv.org/abs/2606.26618v2) | In Khmer/Korean experiments, training loss and human listening preferred different ranks; adaptation gains depended on the language. | Direct TTS evidence for listening evaluation and language-specific ablations. Do not copy its rank 64 into Qwen without testing. |
| [AnLR-LoRA (September 2026 preprint)](https://arxiv.org/abs/2609.05885) | Adapts rates for individual rank-one components using Adam signals; evaluated on language and vision-language benchmarks. | Track as a later optimizer experiment. First establish the simpler two-group LoRA+ baseline; this paper supplies no Mongolian TTS validation. |

These sources motivate hypotheses, not a guarantee of improvement. They use
different architectures, languages, datasets and budgets. This is a focused
engineering review, not an exhaustive systematic review.

## Registered comparison for this round

Before inspecting the new runs' metrics:

1. Train a ratio-1 control and LoRA+ ratio-4 candidate from the exact historical
   epoch-one adapter **and its matching optimizer**. Use 176-update maximum,
   rank 16, dropout 0.05, identical deterministic clip order, and B LR
   1e-5 to 3e-6. Evaluate every 44 updates; patience 2 with cumulative 0.002
   improvement threshold. The parent is eligible to win.
2. Save the absolute lowest validation loss independently of the threshold for
   patience. Save matching optimizer/RNG with every selected checkpoint, so a
   future continuation cannot accidentally combine update-88 weights with
   update-176 optimizer state.
3. Generate the same 44 validation cases at seed 2026 for both selected runs.
   Compare against the current incumbent with pinned ASR, references, decoding,
   and verified model/audio hashes. Report WER and CER for every candidate.
4. Pick the lowest-WER challenger (CER breaks ties). Confirm that challenger
   against the incumbent at seed 2027, without changing hyperparameters or
   selecting individual recordings. If seed-2026 improvement does not persist,
   retain the incumbent. Promotion is provisional and requires lower pooled WER
   over both seeds without pooled CER regression; report uncertainty clustered
   by speaker across seeds. If no challenger improves seed-2026 WER, retain the
   incumbent and record the negative result.
5. Do not treat ASR as a naturalness or speaker-similarity score. Human blind
   listening remains necessary before calling a model a perceptual winner.

## Adapter capacity diagnostic

The incumbent contains 233 adapted linear layers. Computing singular values
of the small QR-factor product (rather than allocating each dense B A update)
gives these medians:

| Component | Adapted layers | Rank retaining 90% update energy | Rank retaining 99% update energy |
| --- | ---: | ---: | ---: |
| Talker decoder | 196 | 7 | 15 |
| Text projection | 2 | 3.5 | 10.5 |
| Residual predictor | 35 | 10 | 16 |

All currently use rank 16. This is a diagnostic of the learned adapter update,
not the pretrained weights, gradients, or perceptual importance of discarded
directions. It does not justify automatically compressing to rank 7 or raising
every layer to rank 64. It motivates measuring layer-specific capacity in a
future fresh-run comparison. Artifact: `incumbent-adapter-spectrum.json`.

## Reproduction additions

Use the pinned local environment and external paths from the audit. The
LoRA+ configuration changes only `loraplus_b_to_a_ratio` relative to the control.
`peak_lr` and `end_lr` always denote B's rates; A receives one quarter in ratio 4.

```powershell
python -m training.engine --base <base> --backup <backup> --features <features> --init-checkpoint <historical-resume.pt> --validation-cache <incumbent>/validation-features.pt --config configs/qwen06-loraplus.json --output <external>/literature-loraplus-r4
python -m training.evaluate --base <base> --run <candidate> --epoch-one <historical-run> --backup <backup> --asr <pinned-asr> --seed 2026 --baseline-evaluation <incumbent>/speech-validation
python -m training.compare_experiments --baseline <incumbent> --candidate <candidate> --seeds 2026 2027 --output <external>/paired-comparison.json
python -m scripts.analyze_lora_spectrum --adapter <selected-adapter.pt> --output <external>/adapter-spectrum.json
```

`--validation-cache` verifies the same cohort/feature signature before reuse.
Different generation seeds use separate output folders; mismatched plans are
rejected. Compare generation seed 2027 only with another seed-2027 evaluation.
The historical initializer remains specific to historical checkpoints; selected
new checkpoints retain all state for a future explicit fork implementation.

## Continuing optimization

The implementation passes all **84 repository tests**. Tests cover moment
preservation when splitting optimizer groups, identical resumed updates,
independent checkpoint/patience selection, speaker clustering across seeds,
and agreement between the small-matrix spectrum and a dense reference.
Both actual selected checkpoints also passed checksum, source snapshot, FP32
parameter/moment, learning-rate-ratio, and weight/optimizer-step verification.

## Generated-speech results and decision

All 44 cases completed for both challengers with seed 2026, using the same
references, generation settings and pinned ASR as the incumbent. These are
pooled punctuation-free scores over 438 reference words and 2,830 characters.

| Model | Selected continuation update | CER | WER | Word errors |
| --- | ---: | ---: | ---: | ---: |
| **Incumbent: FP32 continuation v4** | **88** | **5.65%** | **13.24%** | **58** |
| Updated ratio-1 control | 132 | 5.72% | 14.38% | 63 |
| LoRA+ B/A = 4 | 44 | 5.94% | 15.75% | 69 |

**Decision: retain the incumbent; do not enable LoRA+ by default.** Neither
challenger improved first-seed WER, so the registered protocol did not trigger
second-seed confirmation. Multi-seed support is implemented and tested, but
these model results are still single-seed development results.

Speaker-clustered 95% bootstrap intervals for WER change relative to the
incumbent were **[-2.60, +6.30] percentage points** for the control and
**[-2.15, +8.31] points** for LoRA+. Both include zero. The small sample does
not prove either method is worse generally; it does not support promotion.
This experiment evaluates short continuations with a preserved historical Adam
state, not fresh LoRA+ training or all possible A/B rate ratios.

Lower teacher-forced loss did not translate into better ASR error for the
control. Keep the absolute-best-loss checkpoint fix as a correctness improvement,
but require generated speech before changing the selected model. Retain the
FP32 parameters/moments, source snapshots, cache verification and matching
selected optimizer checkpoints.
