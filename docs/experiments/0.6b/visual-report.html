05 / Experiment atlas

The full investigation, by question.

Completed experiments, rejected approaches, and diagnostics are retained. Expand a family to see what changed and why.

Literature follow-up · conditional / not selected

Options only after the current pilot finishes

1. Fresh generated-trajectory diagnostic

Qwen3-TTS, GLM-TTS and GSPO motivate testing fresh joint pronunciation/voice rewards. First verify fitting-only variation and exact sampler replay. Adjacent systems do not establish a Mongolian result; fixed-pool DPO already failed.

2. Verified pronunciation input

Only if qualified Mongolian labels confirm audible lexical errors. UtterTune improved targeted Japanese accent control but worsened general CER. No validated frontend or voice-preservation guarantee is assumed.

Neither option is implemented, selected or registered. No repeat base-KV recipe is prioritized. Same calibration80 and original114 gates; confirmation comes first if the live pilot qualifies. Primary sources and detailed limits are in the embedded report.
