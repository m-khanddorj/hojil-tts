# Reserved test: epoch 3 versus epoch 2

Registered November 10, 2026 after the user requested evaluation of the
selected epoch-3 model against the previous best, epoch 2. Both checkpoints
were fixed before opening the reserved test evaluation. This is an evaluation
of the existing models; no training or decoding optimization is performed.

## Scope and protocol

Use all **30 targets from 10 reserved unseen test speakers** in
`unseen-test.jsonl`, at generation seeds **2026 and 2027**: 60 recordings per
model, 120 total. The separate 1,764-row familiar-speaker test cohort is not
included in this unseen-speaker benchmark. Every target has a distinct,
same-speaker reference from the test split for voice cloning.

Verify cohort hashes against both the original cohort metadata and recovery
receipt, and verify the canonical dataset manifest. Check target and reference
identity, audio path, PCM hashes, normalized text and speaker membership against
training and development. The reserved speakers must exactly match the
original test-speaker assignment. All checks passed before synthesis.

Model hashes and selected-adapter hashes are frozen in the external
`heldout-epoch3-vs-epoch2/protocol.json`. Both models use the same generation
settings as development: Auto language, non-streaming conditioning, temperature
0.9, top-p 1, top-k 50, maximum 320 generated tokens. Reset the seed for every
case. ASR uses the same pinned BuzzASR Mongolian revision and deterministic
decoding as development. Score pooled punctuation-normalized CER/WER, retain
every output, and cluster bootstrap uncertainty by speaker across both seeds.

Test caches live under `speech-unseen-test` and
`speech-unseen-test-seed-2027` within each model run, separately from development
caches. Test score provenance records the model, selection, plan and evaluation
source hashes. Training checkpoints and development scores remain unchanged.

## Result

**Epoch 2 performed better on this reserved unseen-speaker test.** Epoch 3's
development-set improvement was not reproduced on the pooled test scores.

| Seed | Epoch 2 CER | Epoch 2 WER | Epoch 3 CER | Epoch 3 WER |
| --- | ---: | ---: | ---: | ---: |
| 2026 | 4.78% | 12.50% | 4.72% | 11.72% |
| 2027 | 4.17% | 9.38% | 6.38% | 15.23% |
| **Pooled** | **4.48%** | **10.94%** | **5.55%** | **13.48%** |

The pooled denominators are 512 reference words and 3,262 reference characters
per model. Epoch 3 added **13 word errors and 35 character errors**: WER rose
**2.54 percentage points**, or 23.2% relative, and CER rose 1.07 points. The
speaker-clustered 95% bootstrap interval for the WER change is **[0.00, +5.08]
percentage points**. With only ten speakers and an interval touching zero, this
is evidence favoring epoch 2 on this sample, not a precise population estimate.

Epoch 3 was slightly better at seed 2026 and substantially worse at seed 2027.
It worsened pooled WER for eight of ten speakers. At the recording level it
improved 13, tied 28 and worsened 19. Recordings with WER at least 50% increased
from one to four. Seed-2027 cases 009, 019 and 022 added five, four and three word
errors respectively. All remain included. Case 019's duration increased from
4.64 to 8.72 seconds; this is a review flag, not a listening-quality verdict.

The examples remain the three cases chosen before scoring, including case 001,
where both models have appreciable ASR error. No alternative recordings or
seeds were selected to make either model sound better. The report includes
both models, target text, reference audio and an all-case blind listening page.

## Interpretation

Epoch 3 remains the historical development-selected checkpoint; this test does
**not** support replacing epoch 2 on the basis of generalization. No deployment
or model-selection pointer was changed by this evaluation. Both checkpoints
are preserved. Prefer epoch 2 when judging these test ASR results, and review
naturalness/voice similarity by listening before a deployment choice.

The reserved test has now been examined. Do not use it for repeated tuning and
continue calling the resulting comparisons an untouched final test. Any new
recipe selection should use development data, with fresh independent evidence
for a later final claim. No human ratings were collected here.

All 120 generated recordings were retained and provenance-verified. Evaluation,
diagnostics and listening-page generation completed successfully; the 106-test
suite and final JavaScript/whitespace checks passed.

expanded ranking is **exploratory**. The lowest observed test WER among six

two-model conclusions remain historical comparisons, not a claim about all
subsequently inspected checkpoints.
