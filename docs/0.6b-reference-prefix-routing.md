# Reference-prefix weight routing

Centered speaker update 16 passes both development targets but fails the
custom-reference targets. A separate inference experiment is prepared to test
whether processing the reference prompt with the halfway model's matrices
retains more voice information while full adapted matrices handle the target
text and generated speech.

This differs from the earlier target-only text-projection transfer, which
kept the main decoder halfway throughout generation. It also differs from
restoring the residual code predictor, which left all main-decoder prompt
processing fully adapted. Neither earlier comparison tested this boundary.

## Planned intervention

Start from audited centered update 16 and keep its speaker input adapter
unchanged. During the single native nonstreaming prefill, reference/control
rows use matrices interpolated halfway between the original base and the
exported full epoch-2 endpoint. Target-transcript rows use the full matrices.
Every cached generated frame subsequently uses full matrices.

The candidate routes 196 main-decoder linear matrices and the two text-
projection matrices. Main/residual output heads, code predictor, codec and
speaker encoder remain full/frozen as in the baseline. There is no optimizer.
The stored acoustic parameters never change; alternate matrices are used by
the reference branch. Attention couples the branches, so this does **not**
claim unchanged target hidden states or a completely isolated voice circuit.

The hypothesis is inspired by component weight transfer and the observed
halfway/full tradeoff. It is not a reproduction of the original Weight-Space
Programming report or evidence that reference routing will improve speech.

## Required checks

Three CPU tiny-Qwen tests pass: no-op native codec parity, correct reference/
target/decoded-row matrix selection, and unchanged parameters plus cleanup
after an injected decoder failure. They verify one prefill, cached decoding,
and the expected Auto-language full-ICL layout. Other conditioning modes and
batching are rejected for this experiment.

The actual model must reproduce centered update-16 custom-001/seed-2026 audio
with routing disabled before any candidate evaluation. Then generate all 26
fixed screen recordings using the existing CPU FP32, prompts and seeds. Save
sampled codec sequences, EOS, routing spans and model/matrix identities along
with audio. Score CER/WER and original-reference cosine; independently audit
all 198 matrices, frozen states, codec trajectories, routing spans and scores.
A screening pass still requires the registered 114-recording confirmation.

The centered run completed without a joint pass, stopped under its custom-
regression rule, and its final checkpoint passed the independent audit. The
reference-prefix comparison has now been registered and launched separately.
Its real-model no-op control reproduces centered update-16 custom-001/seed-2026
audio exactly. All 198 alternate matrices, the full acoustic model and the
speaker adapter retain the same hashes before and after the control.

The control records one 117-position prefill, target-text positions 36 through
66, and 70 cached decode steps. Routing is disabled for that control. The
protected candidate's full 26-recording generation is running; no speech-
quality result exists yet. Artifacts remain outside Git in
`reference-prefix-half-routing/`. Registered source modules must stay immutable.

## Completed comparison

All 26 recordings completed without truncation. Independent verification
passes all 198 matrices, acoustic/speaker state, audio/trajectory hashes,
sampled codec sequences and EOS, routing spans, ASR edits and aggregates.
Re-extracted cosines match exactly under the audit's four-thread CPU setting.

| Group | Centered-16 CER / WER | Routed CER / WER | Centered-16 cosine | Routed cosine |
| --- | ---: | ---: | ---: | ---: |
| Development | 1.68% / 5.75% | 4.93% / 14.37% | 0.984636 | 0.984177 |
| Custom reference | 3.74% / 9.38% | 5.61% / 15.63% | 0.977098 | 0.985578 |

Both voice thresholds pass, but both CER thresholds fail. Custom cosine
recovers strongly while pronunciation deteriorates. The pipeline exits
successfully; there is no confirmation or promotion.

This motivates an [audio-prefix-only ablation](0.6b-reference-codec-routing.md):
keep complete text/control processing fully adapted and route only the later
reference codec/BOS rows. The broader routing result does not prove which
reference component caused the pronunciation loss.
